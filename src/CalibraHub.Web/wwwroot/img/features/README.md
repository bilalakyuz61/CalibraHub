# Öne Çıkan Özellikler — ekran görüntüsü listesi

Sayfa: Ayarlar → Öne Çıkan Özellikler (`/Admin/Features`)

Görselleri aşağıdaki adlarla bu klasöre koyun; sayfa dosyayı bulunca otomatik gösterir,
bulamayınca kart görselsiz çıkar. Uzantı `.png`, `.jpg` veya `.webp` olabilir.
`_hero` = modül kapak görseli (geniş), diğerleri kartta 16:9 kırpılır.

Eksikleri ekranda görmek için sayfadaki **Eksik görselleri göster** anahtarını açın.
