The Send Detail screen shows the per-recipient results of a bulk mail send.

What Is This Screen For?

  • Summary of the send: subject, template, Total / Sent / Failed counts.
  • The status (sent / failed) and the error message are listed for each recipient.
  • A printable recipient list and a mail preview can be opened.

Note: This screen is read-only; use "New Send" on the Bulk Mail screen for a new send.
