The Production tab controls the security rules of the production terminal (ShopFloor) and recipe/work order behavior.

Failed PIN Attempt Limit

On the production terminal, operator identity is verified with a PIN or NFC card. After the specified number of failed PIN attempts the person is automatically blocked and can no longer post transactions.

  • To unblock: reactivate the person from the Personnel card.
  • Entering 0 disables locking (not recommended).

Same Component on Multiple Recipe Lines

When enabled, the same material may be used on separate lines of one recipe (for example the same paint at two stages). When disabled, a repeated component cannot be saved — this prevents accidental duplicate lines.

Editing the Recipe of a Started Work Order

Allows the component list of a work order that has already started or already consumed material to be modified. Keeping it off is safer for traceability; shops that frequently swap materials mid-production may turn it on.

Note: These parameters affect new transactions. Past production records and completed consumptions remain unchanged.
