The Scheduled Task Edit screen defines when an automated task runs and what it does.

Fields

  • Task name and status (active/inactive).
  • Schedule: Cron expression or interval (e.g. every day at 02:00, every hour).
  • Job to run: Task type and its parameters (e.g. which report/integration).

Saving

Save stores the task and adds it to the schedule; Back returns to the list without saving.
