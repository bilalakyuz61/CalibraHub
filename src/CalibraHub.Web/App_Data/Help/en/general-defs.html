The General Definitions screen lets you manage the country, city, district, neighborhood/village and region reference lists used in addresses.

What Is This Screen For?

  • Countries → Cities → Districts → Neighborhood/Village: Hierarchical address references.
  • Region / Sub-Region: Additional regional classifications.
  • These lists feed the address fields on account, delivery address and similar screens.

Cards and Actions

  • Manage the reference records with New / Edit / Delete.

Note: The standard lists come pre-loaded at setup; you only add/edit them for special needs.
