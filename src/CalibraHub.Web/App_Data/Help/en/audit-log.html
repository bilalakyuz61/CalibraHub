The Audit Log screen is the audit record where you track insert, update, delete and session events in the system. It answers the question of who changed what, and when.

What Is This Screen For?

  • Each row shows one operation: user, date/time, operation type, record and changed fields.
  • For updates, only the changed fields are kept as "old → new".
  • Use search / filter to narrow down by user, date range, operation type or record.

Note: The "Change History" section on a record's edit screen shows the logs specific to that record; this screen is the central audit view of the entire system. The log retention period is configured in Company Parameters.
