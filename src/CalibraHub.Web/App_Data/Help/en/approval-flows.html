The Approval Flow Definitions screen is where you define which approval process documents and records go through. Each flow is a visual process that sets the steps, approvers and conditions for a document type.

What Is an Approval Flow?

When a document (e.g. a purchase order, a work order) is submitted for approval, the appropriate flow is matched automatically based on the document type and rules (amount threshold, tax ID, department). The steps in the flow are routed to the relevant people in order; approvers process them on the Pending Approvals screen.

Cards

  • The header shows the flow name, below it the document type; on the right an Active / Inactive badge.
  • Info badges: Step Count, Condition Count, Document Type.
  • Card actions: Edit (opens the designer), Delete and Copy (the copy is created as inactive).

New Flow

New Flow at the top opens an empty visual designer; you set the flow name and document type and add the steps. For detailed help on the designer screen, use Actions → Help there.

Note: If a document type has more than one active flow, the first flow whose rules match takes effect.
