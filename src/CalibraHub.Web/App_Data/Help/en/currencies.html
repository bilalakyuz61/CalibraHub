The Currency Definitions screen lets you manage the currencies you use and their daily exchange rates in one place. Currency conversions on documents are performed using these rates.

What Is This Screen For?

  • Currency definitions: You define currencies such as USD, EUR, GBP.
  • Rates: Date-based buy/sell rates are kept for each currency. Rates can be fetched automatically (Central Bank) or entered manually.

Usage

  • Rate update fetches the values for the current day; historical rates are preserved.
  • During document entry, the appropriate rate is applied automatically based on the selected currency and date.

Note: The local currency is used as the base; in reports, amounts are converted to the local currency using these rates for comparison.
