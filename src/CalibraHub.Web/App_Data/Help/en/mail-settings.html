The Mail Settings screen manages the SMTP profiles the system uses to send e-mail (system/dev area).

What Is This Screen For?

  • The SMTP server, port, SSL, sender address and credentials are defined here.
  • The active profile is used for Bulk Mail, approval notifications and other system e-mails.

Note: For everyday use, the same settings are also accessible from the Mail/SMTP tab in Company Settings; this page is in the System Settings area.
