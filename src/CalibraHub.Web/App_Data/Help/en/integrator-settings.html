The e-Document Integrator Settings screen configures the connection and credentials of the e-Document (e-Invoice/e-Archive/e-Delivery Note) integrator (system/dev area).

What Is This Screen For?

  • The integrator service address, username/password and environment (test/production) are defined here.
  • The Electronic Documents screen retrieves documents over this connection.

Note: The credentials are sensitive; only the System Admin can access them.
