The Material Cards screen lists all of your raw material, semi-finished, finished good, trade good, consumable and kit definitions in a card view. From here you create new cards, search, filter, export to Excel and open cards to edit them.

Top Toolbar

The standard tools appear at the top of the screen, from left to right:

  • Search: Instant filtering by code or name.
  • Filter: Advanced filtering by card fields (type, group, unit, etc.). When a filter is active, a marker appears on the indicator.
  • Excel: Exports the visible cards along with their columns.
  • Column/Widget settings: Determines which data fields are shown on the cards and in what order (your preference is saved per user).
  • New Material: Opens a blank material card edit screen.

Cards

  • Each card represents one material; the title shows the name, with the code and the selected data fields (type, unit, stock, price, etc.) below.
  • Click a card to edit it — the material card edit screen opens.
  • To delete, use the delete action on the card; confirmation is required. After deletion, the list updates only the affected card (the page does not reload).

Tips

  • Use the Filter panel to focus on a specific type (e.g. Finished Goods only).
  • When there are many cards, narrow down with the search box first, then edit.
