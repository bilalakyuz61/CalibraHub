The Permission Management screen lets you specify, on a matrix, which actions (view, add, edit, delete) each role can perform on which screens.

What Is This Screen For?

  • Rows represent screens (forms), columns represent action types.
  • For a role, check the relevant cell to grant/revoke that screen+action permission.
  • Screens without permission do not appear in the user's menu and cannot be accessed.

Note: System Settings / developer tools are open only to the System Admin and cannot be granted here; all other business screens can be granted.
