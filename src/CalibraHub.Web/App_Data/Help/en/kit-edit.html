The Kit (Bundle Product) Edit screen defines the contents and pricing method of a bundle product in which multiple materials are sold together.

What Is a Kit?

A kit is a bundle product that is not stocked as itself but is "exploded" into its components at the time of sale (e.g. a Table + 4 Chairs set). The order is taken for the kit itself, and shipment is made with its components.

Fields

  • Kit details and version.
  • Component lines: The materials that make up the bundle and their quantities.
  • Price mode: Fixed bundle price or sum of components (roll-up).

Saving

Save stores the record; Back returns to the list without saving.

Note: In sales documents the kit is tracked as a complete set; set integrity is preserved in partial deliveries.
