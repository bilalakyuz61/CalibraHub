The Defined Combinations screen lists all active combinations (attribute-value pairings) created for variant products in a card view.

What Is This Screen For?

Each card shows one combination (e.g. "T-Shirt · Red · L"). Here you get an overview of which variants are defined for which products.

Editing

Clicking a combination opens the Combinations tab of the related material card; combinations are generated and managed there. This screen has no edit page of its own — it is a general overview/access list.

Note: To generate new combinations, first define the attributes on the "Attributes and Combinations" screen, then enable combination tracking on the material card.
