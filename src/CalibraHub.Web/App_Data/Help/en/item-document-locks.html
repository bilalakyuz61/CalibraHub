The Material Document Locks screen defines which document types certain materials cannot be used in (i.e. are locked for). For example, if a material is no longer offered for sale, you can prevent it from being selected in sales documents.

What Is This Screen For?

Each record shows one material + document type lock. A locked material cannot be selected in the line items of the related document type (quote, order, delivery note, warehouse receipt/issue, etc.); this prevents incorrect usage.

Cards and Actions

  • The card shows the material and the locked document types.
  • New / Edit: You select which document types are locked for a material.
  • Delete: Removes the lock (the material becomes usable again).

Note: The lock only restricts the selected document types; the material card itself is not deleted and remains usable in other document types.
