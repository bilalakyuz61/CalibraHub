The Personnel Edit screen defines/edits the information of a production employee.

Fields

  • Name (required; uniqueness is enforced by name — no code is entered).
  • Department and status (active/inactive).
  • Terminal sign-in: PIN and/or NFC card information (for authentication on the ShopFloor).
  • Shift and additional details, if applicable.

Saving

Save stores the record; Back returns to the list without saving. If another employee with the same name exists, the save is blocked.
