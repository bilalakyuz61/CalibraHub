Database Import lets you bring records from another SQL database into CalibraHub using a mapping definition. An import can be re-run safely: the same record is not inserted twice.

Flow

  • You define the source database on the Connections screen.
  • The Wizard selects the source table/query and maps columns to CalibraHub fields.
  • On this screen you see the defined imports, run them and follow their results.

Things To Watch

  • A key field is mandatory — it is how the system knows whether a record was already imported.
  • Stock import is a balance mirror, it does not create movements; if you need movements, create a count sheet and post it.
  • Review the preview before running; invalid rows are listed there.
