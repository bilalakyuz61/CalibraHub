The Feature Edit screen lets you manage a single product feature, the values it can take, and the materials that use this feature.

Fields

  • Feature name (e.g. Color, Size).
  • Values: The options the feature can take (e.g. S, M, L, XL) — you can add, reorder, and remove them.
  • Linked materials: The variant products that use this feature.

Saving

  • Save stores the changes; Back returns to the list without saving.
  • Deleting a value that is in use may affect existing combinations; do this carefully.
