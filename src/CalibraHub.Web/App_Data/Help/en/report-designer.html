The Report Designer is the drag-and-drop design screen where you turn your data into visual panels (chart, table, KPI, map…). The panel palette is on the left, the layout canvas in the middle, and the selected panel's settings on the right.

Data Source

The report is fed by a page-level data source; panels inherit it. Source options:

  • Program views (ready-made data views),
  • a saved SQL source (with cache/snapshot settings),
  • or directly written free-form SQL.

Panel (Visual) Types

Drag panels from the palette onto the canvas — many types including line, area, bar, pie, combo, waterfall, scatter/bubble, radar, gauge, heat map, KPI, table, pivot, text, Gantt, and map (TR/world).

Fields, Metrics, and Summaries

  • Metric + aggregation: Sum, Average, Count, Distinct Count, Min, Max.
  • Grouping: By a field (date grouping on time fields).
  • Table panel: Column visibility, title/format (currency/percent/date/duration), alignment, total/summary row, sorting.
  • Pivot panel: Cross-tab with multi-field rows/columns/values.

Filters and Layout

  • If you enable a column for filtering, a filter control automatically appears on the left.
  • Panels are moved and resized with drag and drop on a 12-column grid.
  • Undo / Redo: Ctrl+Z / Ctrl+Y.

Cache and Scheduling

For saved SQL sources there are two modes for report performance: live query with a timed cache (TTL), or a physical snapshot table. Snapshots can be refreshed automatically by scheduled tasks.

Saving and Presentation

  • Provide a title, group, and description, then store the report with Save.
  • The saved report appears in the Report Designs list and is presented to end users in Report Boards.
  • Excel / PDF export is done on the board that displays the report.

Note: An access permission is created automatically for every saved report; only authorized users can view the report.
