The Scheduled Tasks screen is where you define and monitor jobs that run automatically at set intervals (e.g. report snapshots, integration sync, log cleanup).

Cards and Actions

  • The card shows the task name, schedule (cron), last run, and status.
  • New Task: You define the schedule and the job to run.
  • Edit / Activate / Delete and run history actions.

Note: Tasks run in the background on the server; the result of each run (successful/failed) is kept in the history.
