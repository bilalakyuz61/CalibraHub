The Task Templates screen lets you define recurring project workflows (e.g. sampling process, APQP, commissioning checklist) as ready-made task sets.

What Is a Template?

A template consists of sequential task steps (task name, responsible role, duration/due date, dependencies). When you choose "Apply from Template" in a project, these steps are added to that project as tasks in bulk — saving you from entering tasks manually every time.

Usage

  • + New Template: You define the template and its steps in a panel that opens on the same screen.
  • You can edit an existing template, add or remove steps, or delete it.

Note: Templates are definitions only; the actual tasks are created when the template is applied to a project and are then managed independently within that project.
