The Integration Wizard creates/edits an external system integration step by step — connection, data mapping and trigger rules.

Steps

  • Connection: Target system, address/credentials and API profile.
  • Mapping: The correspondence between CalibraHub fields and external system fields; code conversions and constant/calculated values.
  • Trigger: When the transfer will run (on save, scheduled, manual).
  • Error behavior: Stop on error / skip / retry.

Saving

Save stores the integration; you can test it and put it into service.

Note: In mappings, comparisons are made by identifier (ID); code/name fields are for display only.
