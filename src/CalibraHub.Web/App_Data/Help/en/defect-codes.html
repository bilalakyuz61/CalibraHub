The Defect Codes screen defines the defect code catalog used to classify quality nonconformities (e.g. Scratch, Out of Tolerance, Color Difference, Missing Part).

What Is This Screen For?

When a check line falls outside tolerance during an inspection, the selected defect code comes from this list. This way nonconformities are classified and reported in defect analysis (e.g. most frequent defects).

Cards and Actions

  • The card shows the defect code name and its category, if any.
  • New / Edit: Edits the defect code.
  • Delete: Removes the code.
