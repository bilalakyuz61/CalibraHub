The Document Edit screen is the shared screen where you edit the header and line items of sales and purchasing documents (quotes, orders, delivery notes, purchase requests).

Header Details

  • Account (customer/supplier), document date, currency, and validity/due date if applicable.
  • The document number is usually assigned automatically.

Line Items

  • Each line contains material, quantity, unit, unit price, discount, and VAT; amounts are calculated automatically.
  • Prices may be filled in automatically based on the account/price list. Quick line entry with Enter and pasting from Excel are supported.
  • Custom Fields: Custom fields defined for this form appear in a separate section.

Saving and Conversion

  • Save stores the document; Back returns to the list without saving.
  • Depending on its status, the document can be converted to the next step (quote→order, order→delivery note, etc.) or submitted for approval.
  • Delivery note types create stock movements; quotes/orders do not.

Note: The change history can be tracked from the "Change History" section on the related record.
