The Notes screen is a rich-text notebook where you keep personal and company notes. It is a three-column workspace with a folder tree on the left, the note list in the middle, and the editor on the right.

Notes and Folders

  • Create / edit / delete notes; deleted notes go to the Trash, from where they can be restored or permanently deleted.
  • Folders are hierarchical; you can move notes between folders with drag and drop.
  • Pinning: Important notes stay at the top of the list.
  • Find your notes quickly with tags, search, and sorting (by name/date).

Rich Text Editor

Headings, bold/italic/underline, lists and task lists (checkboxes), tables, code blocks, color/highlight, alignment, links; plus images (including paste from clipboard) and YouTube embedding are supported.

Attachments and Media

  • File attachments (per note, up to 20 MB).
  • Add audio recordings, drawings / whiteboards, and camera photos.
  • OCR: Text in images within a note is automatically extracted and included in search.

Reminders

You can set per-note reminders, configure recurrence (repeating), and target the reminder at other users as well.

Sharing and Visibility

  • Visibility: Private (only you) or Company (company-wide).
  • User sharing: Share with specific people with view/edit permission.
  • Public link: A tokenized share link that requires no sign-in can be created.

Security — Encryption

Two modes: encrypting a selected text block or encrypting the entire note end to end. Encrypted content cannot be read on the server; it can only be opened with your password.

Import / Export and Focus Mode

  • Import: Evernote (.enex) notes.
  • Export: The note as a PDF.
  • Focus mode (F11): Hides distracting elements so you focus only on writing; press F11 again to return to the normal view.

Note: A note can be linked to a record (account, personnel, document, etc.); this keeps related notes tagged together.
