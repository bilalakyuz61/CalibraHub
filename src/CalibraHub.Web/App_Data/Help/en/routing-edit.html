The Routing Edit screen sequences the operation steps of a production routing. The routing defines which operations a finished product goes through and in what order.

Fields

  • Routing name (required; uniqueness is based on the name — no code is entered).
  • Steps: Operations are added in sequence; a sequence number and the related machine can be specified for each step.

Saving

Save stores the record; Back returns to the list without saving.

Note: When a work order is released, this routing is exploded to build the work order's operation list.
