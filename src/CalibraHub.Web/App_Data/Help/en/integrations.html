The Integrations screen lists and manages the integration definitions that connect CalibraHub to third-party systems (e.g. ERP/Netsis, e-commerce).

What Is This Screen For?

Each record represents one integration; it defines which system, which data (accounts, stock, documents) and in which direction the transfer takes place. From here you create new integrations, edit existing ones, and monitor the run logs and the transfer queue.

Actions

  • New Integration: Opens the wizard.
  • Manage the integration with Edit / Activate / Delete.
  • Follow the details on the Endpoints, Run Log and Transfer Queue pages.

Note: This module is for live system integration; for manual bulk uploads from files, use the "Data Import" module.
