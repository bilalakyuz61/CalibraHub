The Data Visibility Rule Edit screen defines the scope and conditions of a masking rule.

Fields

  • Screen / data: The screen or data set the rule applies to.
  • Scope: Which user/role/department it applies to.
  • Condition: Which records will be shown/hidden (e.g. only the user's own records) and the fields to hide.

Saving

Save stores the rule; Back returns to the list without saving.
