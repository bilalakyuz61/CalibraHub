The Feature and Combination screen is where you define features (color, size, material, etc.) for variant products and the values those features can take.

What Is a Feature?

A feature (e.g. "Color") and its values (Red, Blue, Green) are defined. A product with "combination tracking" enabled on the material card has variants made up of value combinations of these features (e.g. Red-L, Blue-M).

Cards and Actions

  • Each card shows a feature and its value count.
  • New / Edit: Edits the feature, its values, and the linked materials.
  • Delete: Removes the feature.

Note: The defined feature-values are used on the material card's "Features / Combinations" tab; the generated combinations are listed on the "Defined Combinations" screen.
