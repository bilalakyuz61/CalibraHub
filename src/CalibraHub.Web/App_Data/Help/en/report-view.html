The Report Viewer runs the selected report with live data and displays its panels (charts, tables, KPIs, etc.) in read-only mode.

Usage

  • You can switch between report pages/tabs.
  • If defined, use filters to narrow down the data; drill-down may be supported on charts.
  • Use the Excel / PDF export buttons to turn the report into shareable output.

Note: Depending on its source, the data comes either live or from a scheduled snapshot; the report design cannot be changed from this screen.
