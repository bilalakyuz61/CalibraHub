The Work Order Edit screen lets you manage a finished product's production order in full detail. Section links are on the left, the selected section's fields on the right, and a fixed toolbar (Back / Save) at the top.

General Information

  • Number and date are assigned automatically (cannot be changed).
  • Product Code (required) — the finished product to be produced. For variant products, the Configuration Code is also selected.
  • Planned Quantity (required) and unit.
  • On new records, the "Plan for Production" switch: when on, the order moves directly to Released status after saving (the routing is exploded).
  • In edit mode, Produced / Scrap / Actual Start-End details are also shown.

Planning Information

Priority, planned start/end dates, responsible personnel, machine, routing (if blank, found automatically based on the product), production location (warehouse/location), and the related R&D / product development project.

Routing / Operations

The operation steps of production (sequence, operation, machine, duration, produced/scrap, status). "Explode from Routing" creates the steps from the product's routing; an operation can also be added manually. After the order is released, progress is recorded from the Shop Floor Terminal using Start / Partial Finish / Finish.

BOM (Components)

The components required for production: net requirement, issued quantity, scrap %, unit, consumption location, and notes.

  • Explode BOM: Builds the component list from the product's bill of materials.
  • Enter Consumption: Deducts the components from stock (stock issue). The source warehouse is the work order's warehouse; the consumption location can be changed per component.

Source Orders

The sales order line(s) that triggered this work order. As orders are linked, the planned quantity is updated accordingly.

Additional Fields

Custom fields defined for the work order form in "Field Management" are added as a separate section.

Production Flow and Stock Effect

  • Flow: Planned → Released → In Progress → Completed → Closed. A routing is required for release (exploded automatically).
  • Component consumption creates a stock issue (BOM → Enter Consumption).
  • Product receipt is automatic: when the last operation is completed on the Shop Floor Terminal, the product is received into stock. For lot-tracked products the lot = the work order number; for serial-tracked products serials are generated automatically (the foundation of the traceability genealogy).

Toolbar

  • Save (on new records or in Planned status), Back, New.
  • Revise: Opens a new revision (history is preserved).
  • Create Inspection: Starts a quality inspection for this work order.

Note: The change history can be tracked from the "Change History" section on the related record.
