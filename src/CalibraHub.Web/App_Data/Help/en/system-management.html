The System Management screen is a password-protected administration area where system-level settings such as company definitions, database connections, and licensing are managed.

What Is This Screen For?

  • Company Definitions: Define/edit the company (or companies) in the system.
  • Database Settings: Manage connection details.
  • License: License information and status.
  • User Mapping: User/company mappings.

Note: This area is open only to the System Admin and is additionally protected by a password. Use it with care, as it contains critical system settings; an incorrect database setting can affect the operation of the application.
