On the Stock Count Edit screen you create/edit a stock count document. You select a location, enter the counted quantity for each material and see the difference against the system balance.

Fields

  • Header information such as location and date.
  • Count lines: Material, system balance, counted quantity and the automatically calculated difference.
  • For lot/serial-tracked materials, counting can be done per lot/serial.

Saving

  • Save stores the count; once approved, the differences are posted to stock.
  • Back returns to the list without saving.

Note: Try not to enter stock movements while counting; movements between the moment of counting and the moment of approval affect the difference.
