The Document Categories screen defines the category and type tree used to classify files in Document Management.

Structure

A two-level classification is used: Category (top level, e.g. Quality, Human Resources, Technical) and the Type beneath it (e.g. Procedure, Instruction, Form). This category/type is selected when uploading a document.

Cards and Actions

  • Each card represents a category or a type.
  • New Category / New Type: You define them in the window that opens.
  • Edit / Delete: You manage existing records.

Note: Categories and types feed the filters on the Document Management screen and the classification lists shown during upload.
