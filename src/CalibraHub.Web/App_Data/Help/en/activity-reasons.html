The Activity Reasons screen defines the downtime and activity reasons that occur during production (breakdown, setup, break, waiting for material, etc.). These reasons are used in shop floor performance and downtime analysis.

What Is This Screen For?

When an operator stops a job, the reason they select comes from this list; this way downtimes are classified and can be reported (e.g. planned/unplanned downtime, efficiency analysis).

Cards and Actions

  • The card shows the reason name and type.
  • New / Edit: Edits the reason.
  • Delete: Removes the reason.
