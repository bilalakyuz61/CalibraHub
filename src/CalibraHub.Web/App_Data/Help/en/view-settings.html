The Field & Widget Definitions screen is the administration panel where you define the visibility and order of form fields on screens, as well as custom additional fields (widgets).

What Is This Screen For?

  • Field management: Which standard fields appear on a form, their order, and their labels.
  • Custom fields (widgets): By adding fields that are not part of the standard set (e.g. an "ERP code" for a material), you show them automatically on the related edit screen.

Note: Custom fields defined for a form appear automatically in the "Additional Fields" section of that record's edit screen.
