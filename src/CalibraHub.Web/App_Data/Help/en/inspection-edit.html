On the Inspection Edit screen you create/edit a quality inspection. You measure the control characteristics and record the result and the decision.

Header

  • Inspection type (incoming / in-process / final / lab) and the source document (purchase delivery note, warehouse receipt, work order, etc.) with the related material.

Control Lines

  • The characteristics to be checked come from the related material's Inspection Plan (measurement or qualitative check).
  • For each line, enter the measured value/result; if it is out of tolerance, select a defect code.

Decision and Saving

  • Based on the result, a decision is made (accepted / rejected / conditional acceptance).
  • Save stores the inspection; Back returns to the list without saving.
  • In case of nonconformity, a CAPA (corrective/preventive action) can be initiated from this inspection.

Note: The change history and any custom fields can be viewed on the related tabs.
