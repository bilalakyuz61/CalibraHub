The Database Map screen is a system/developer tool that visualizes the table, view, column, and relationship structure of the active company database.

What Is This Screen For?

  • Displays tables, columns, primary/foreign keys, and relationships as a schema.
  • You can export the schema as a diagram (Mermaid) and as CSV / JSON.
  • Only physical metadata (structural information) is read; record/data content is not shown.

Note: This screen is available only to the System Admin; it is a tool for integration, development, and diagnostic purposes. It does not modify the schema.
