The Warehouse Issue (Stock Out) screen lists documents that take stock out of the warehouse. Non-sales issues (consumption, scrap, samples, return issues, etc.) are managed here.

What Is This Screen For?

Each card is a warehouse issue document. An issue document deducts material from the selected location (stock decrease). The card shows the document number, location, line count/amount, and date.

Toolbar and Cards

  • New Issue: Opens the edit screen where you enter the location and line items.
  • Card actions: Edit, Delete, audit log.

Note: If negative-balance control is enabled, an issue may be blocked when stock is insufficient. For lot/serial-tracked materials, the lot/serial is selected during the issue.
