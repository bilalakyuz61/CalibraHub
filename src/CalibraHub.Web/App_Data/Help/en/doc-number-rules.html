The Document Number Rules screen defines how the automatic document number is generated (format and counter) for each document type.

What Is This Screen For?

Each card shows the number rule for a document type. When a new document is created, its number is assigned automatically according to this rule (such as prefix + year/month + incrementing sequence).

Cards and Actions

  • The card shows the document type, a format example, and the current counter.
  • New / Edit: Edits the format and counter settings.

Note: This screen is reached from the Document Number tab within "Design Rules".
