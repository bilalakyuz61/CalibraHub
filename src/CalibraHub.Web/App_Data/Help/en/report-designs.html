The Report Designs screen lists the visual reports and dashboards you have created in a card view. From here you design new reports, edit existing ones, or delete them.

What Is This Screen For?

Each card represents a report design. You can open and edit a design, copy it, or delete it. The reports you design are presented to end users on the Report Dashboards screen (read-only viewing + Excel/PDF).

Cards and Actions

  • The card shows the report title, group name, and description.
  • Edit: Opens the visual report designer.
  • Delete: Removes the design (confirmation required).
  • New Design: Opens a blank designer.

Flow

Design → Save → appear in this list → present to end users on Report Dashboards. For detailed help on the designer screen, use Actions → Help there.

Note: Which users can view a report is controlled by permissions; an access permission is created automatically for every saved report.
