The Design Rules screen manages, in one place, the rules that determine which template documents are printed with, how their numbers are generated, and how account/stock codes are created automatically. Use the tabs at the top to switch between the four rule types.

Tabs

  • Document Design: Determines which design template is used for which document type and which criteria (account, user, branch, warehouse).
  • Document Number: Defines the number format and counter rules (prefix, year/month, sequence number) for document types.
  • Account Code: How the automatic account code is generated when a new account is created.
  • Stock Code: How the automatic stock code is generated when a new material is created.

Cards and Actions

  • On each tab, the relevant rules are listed as cards.
  • New / Edit: Defines the rule; remove it with Delete.

Note: If multiple rules exist for a document/record, the rule that best matches the criteria (the most specific one) is applied; if there is no match, the default is used.
