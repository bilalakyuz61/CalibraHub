The User Definitions screen lets you manage your company's system users in a card view.

Cards and Actions

  • The card shows the user name, e-mail, role, and status.
  • New User: Adds a user (name, e-mail, role, initial password).
  • Edit: Updates details and the role.
  • Reset Password: Renews the user's password.
  • Deactivate: Users are never deleted, only deactivated (soft-delete).

Note: The "System Admin" role can only be assigned by an existing System Admin. What a user can see and do is determined on the "Permission Management" screen.
