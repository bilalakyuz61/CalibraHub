The Shipment Planning Center lets you see how much of each order is ready before dispatch and reserve stock for it.

What Is This Screen For?

  • Open order lines are listed together with stock status and reserved quantities.
  • Reservations are made or released from the Actions menu at the start of the row.
  • A reserved quantity is deducted from the available balance; physical stock is unchanged.

Note: reservation is logical — nothing is physically set aside, it only prevents another document from using the same goods.
