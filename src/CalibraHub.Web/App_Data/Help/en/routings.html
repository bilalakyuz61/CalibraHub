The Routing Definitions screen defines production routings (operation sequences) in a card view. A routing determines which operations a finished product goes through and in what order.

What Is a Routing?

A routing consists of sequential operation steps. When a work order is released, the related routing is "exploded" to build the work order's operation list, which is then progressed in that order on the shop floor.

Cards and Actions

  • The card shows the routing name and step count.
  • New / Edit: Sequences/edits the routing's operation steps.
  • Delete: Removes the routing.

Note: You do not enter a code for a routing; uniqueness is based on the name. If the routing is left blank on a work order, a suitable routing is found automatically based on the finished product.
