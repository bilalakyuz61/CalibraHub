The CAPA Edit screen manages a Corrective/Preventive Action in full detail — source, root cause, actions, owners and closure.

Header

  • CAPA number (automatic), source (inspection / purchase delivery note / account), owner and status.
  • Problem definition and root cause analysis.

Actions

  • The corrective and preventive actions to be taken; each action has an owner and a due date.
  • Actions are marked off as they are completed; effectiveness verification is performed.

Status and Closure

  • A CAPA progresses through a state machine (open → in progress → verification → closed).
  • The CAPA cannot be closed until all actions and the verification are complete.
  • Save stores it; Back returns to the list without saving.
