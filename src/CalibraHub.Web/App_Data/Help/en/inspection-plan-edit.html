The Inspection Plan Edit screen defines the scope and characteristics of a control template.

Header

  • Plan name and scope: which material or material group and which inspection type it applies to.

Characteristics

  • The properties to be checked (e.g. dimension, weight, visual, function).
  • For each characteristic, define the type (measurement / qualitative), the tolerance (lower/upper limit), the unit and whether it is mandatory.

Saving

Save stores the plan; Back returns to the list without saving.
