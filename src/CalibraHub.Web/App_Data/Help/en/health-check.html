The System Health Check screen is a system/diagnostic tool that automatically walks through every screen in the application and verifies that each one loads without errors.

What Is This Screen For?

  • It calls the pages in the menu one by one and reports the HTTP status (success / redirect / error) as a live stream.
  • It lets you quickly identify broken, inaccessible or failing screens.
  • You can watch the results and focus on the problematic pages.

Note: This screen is a diagnostic tool available only to the System Admin; it is typically used for verification after an update/installation.
