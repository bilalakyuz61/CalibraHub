The BOM Edit screen is where you define the bill of materials (component list) of a finished product. Each line specifies a component required to produce the product and its quantity.

Header

  • Finished product (the product the BOM belongs to) and, if any, the configuration (variant).

Component Lines

  • Each line has a component, quantity, unit and scrap %.
  • If a component is a semi-finished product, it has its own BOM — the tree becomes multi-level.
  • Fast entry: Enter-key line chaining, paste from Excel and undo are supported.

Saving

  • Save stores the BOM; Back returns to the list without saving.

Note: When a work order is opened and released, this BOM is "exploded" to create the component requirements and lower-level semi-finished products.
