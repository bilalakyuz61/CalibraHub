The Enum Definitions screen lets you view and edit the fixed value lists (enums) in the integration document catalog.

What Is This Screen For?

  • The valid fixed values (code + description) for the external system's (e.g. ERP) fields are kept here.
  • These values are used as selection lists in integration mappings.

Note: The catalog usually comes pre-loaded from the provider definition; edit it only for special needs.
