The Purchase Requests screen lists the request records created before purchasing. The material and quantity an employee needs are recorded here; these requests are then fulfilled from the warehouse, by transfer, or by purchasing.

What Is a Purchase Request?

It is the first step of the purchasing chain: Purchase Request → Fulfillment → Purchase Demand/Quote/Order. The request itself is not a stock or purchasing transaction; it only holds the "what is needed and how much" information. As it is fulfilled, it turns into a warehouse issue, a warehouse transfer, or a purchasing document.

Top Toolbar

  • Search: Search by request number.
  • Fulfillment Center: Opens the Fulfillment Center to fulfill multiple requests in bulk.
  • New Request: Opens a new purchase request edit screen (material, quantity, and date are entered there).

Cards

  • The header shows the requesting employee, with the document number below.
  • Info badges: Total Amount, Status, Line Count, Date, and Fulfillment status (Waiting → Partial → Completed).
  • Card actions: Edit, Delete, Copy, Send for Approval (on draft records, if the approval flow is enabled), and Audit (audit log).

Fulfillment

Requests are fulfilled from the Fulfillment Center. The main options:

  • Fulfill from Warehouse: Fulfills from existing stock (no purchasing needed).
  • Warehouse Transfer: Fulfills by transfer from another warehouse.
  • Purchasing: Creates a purchase demand or order draft.

As fulfillment progresses, the record's "Fulfillment" badge is updated automatically; the derived documents (issue/transfer/purchase) are tracked as linked to the record.

Approval Flow

If the approval parameter is enabled, the request first goes to approval via Send for Approval; only approved requests can be fulfilled in the Fulfillment Center. If approval is disabled, all requests can be fulfilled directly.
