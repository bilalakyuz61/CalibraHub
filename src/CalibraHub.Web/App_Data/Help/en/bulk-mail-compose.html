The New Bulk Mail wizard lets you select a template and a recipient pool and send a personalized e-mail to each person. It consists of three steps and is completed with Send in Bulk on the top ribbon.

Step 1 — Template & Target

  • Template: Selected from Document Designer designs marked "Also use as mail template". When a template is selected, the subject and body can be filled in automatically.
  • Recipient title: You select the contact title(s) to send to (e.g. Accounting, Purchasing). The "Corporate Contact" option sends to the account's corporate e-mail address.
  • Account group filter: An optional 5-level group to narrow down a large pool.

Step 2 — Mail Body

  • Subject (if left empty the template name is used) and Content.
  • Personalization (tokens): {{personName}}, {{personTitle}}, {{personEmail}}, {{contactName}}, {{contactCode}}, {{currentDate}} added to the content are filled in automatically for each recipient.
  • Attachments: Up to 10 files / 25 MB in total.
  • If the screen was opened from a document, you can send that document's PDF as an attachment.
  • Preview: Shows how the mail will look, using the first recipient.

Step 3 — Recipient List

  • The people matching the filter are listed; you can include / exclude each row.
  • Narrow down with Search; select in bulk with Include / Exclude All.
  • A "X included · Y excluded · total Z" counter is shown at the top.

Note: Recipients come only from the account contact pool via the title/group/search filter — there is no manual e-mail entry or Excel import. An active SMTP profile is required for sending; sending is immediate (no scheduling).
