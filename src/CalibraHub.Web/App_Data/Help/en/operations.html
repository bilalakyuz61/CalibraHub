The Operation Definitions screen defines the operations used in production (cutting, assembly, painting, quality control, etc.) in a card view.

What Is an Operation?

An operation is a step of a production routing. Routings are built by sequencing these operations; when a work order is opened, the operations are dispatched to the shop floor as jobs.

Cards and Actions

  • The card shows the operation name and related information.
  • New / Edit: Edits the operation and its machine/product-based times.
  • Delete: Removes the operation.

Note: You do not enter a code for an operation; uniqueness is enforced by name. Machine- and product-based standard times are defined on the operation edit screen.
