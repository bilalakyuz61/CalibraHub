The Machine Definitions screen defines your production machines in a card view. Machines are the work stations on which operations are performed.

What Is This Screen For?

Each card shows one machine. Machines are used in operation times and in building the job queue in the Shop Floor Terminal.

Cards and Actions

  • The card shows the machine name, type and status.
  • New / Edit: Edits the machine details.
  • Delete: Deactivates/removes the machine.

Note: You do not enter a code for a machine; uniqueness is by name. The machine/warehouse distinction and the default location are set on the machine edit screen.
