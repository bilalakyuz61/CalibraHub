The Inspections screen lists quality control inspections in a card view. Each inspection is an actual event where a material/batch is checked against defined criteria.

What Is an Inspection?

An inspection can be an incoming goods (receiving), in-process, final or laboratory check, and it is usually tied to a source document (purchase delivery note, warehouse receipt, work order). In the end, a decision is made (accepted / nonconforming / conditional acceptance).

Cards and Actions

  • The card shows the inspection number, type, related material/source document, status and date.
  • New / Edit: Opens the inspection record; you enter the measurements and the decision.
  • Delete: Removes the inspection.

Note: When an inspection is opened, the characteristics to be checked come automatically from the related material's Inspection Plan. If there is a nonconformity, a CAPA can be opened.
