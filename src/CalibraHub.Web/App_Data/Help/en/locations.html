The Location Definitions screen lets you define the warehouses and locations where stock is kept (shelf, zone, line-side, etc.).

What Is This Screen For?

Each card shows one warehouse/location. Locations determine where stock movements go to/come from in warehouse receipts/issues, transfers, stock counts and production consumption.

Cards and Actions

  • New / Edit: Manages the location details.
  • Delete: Removes the location.

Note: A material's default location is set on the material card; stock balances are tracked per location.
