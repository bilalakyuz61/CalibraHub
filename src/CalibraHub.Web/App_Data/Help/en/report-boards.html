The Report Boards screen lists the reports/dashboards published for you. From here you open a report to view it.

What Is This Screen For?

  • Each card represents a report prepared in the Report Designer (title, group, description).
  • Only the reports you have view permission for are listed.
  • Clicking a card opens the report viewer.

Note: Report contents and layout are managed on the "Report Designs" screen; this screen is the end-user view.
