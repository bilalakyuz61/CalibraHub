The Number Rule Edit screen defines the number format and counter for a document type.

Fields

  • Document type and format — prefix, year/month components, and sequence number.
  • Sequence length (e.g. 6 digits → 000123) and starting/current counter.
  • When the counter resets (e.g. at the start of each year) can be specified.

Saving

Save stores the rule; Back returns to the list without saving.

Note: Changing the format after numbers have been generated does not affect past documents; it applies only to new documents.
