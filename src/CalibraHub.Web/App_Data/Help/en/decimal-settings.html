The Decimal Settings screen lets you specify how many decimal places are displayed for quantity, price, and amount fields on each screen/form.

What Is This Screen For?

  • Decimal precision is defined per form (e.g. quantity 2 digits, unit price 4 digits).
  • The defined value determines the display and rounding of numeric fields on that form.
  • If no setting is made for a form, the company default is used.

Usage

Enter the decimal values for the relevant form and press Save; you can restore the default with Reset.
