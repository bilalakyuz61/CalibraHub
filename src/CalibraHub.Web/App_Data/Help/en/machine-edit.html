The Machine Edit screen defines/edits the details of a production machine.

Fields

  • Machine name (required; uniqueness is by name — no code is entered).
  • Machine / Warehouse distinction and the default location.
  • Status (active/inactive) and any additional details (brand, capacity, etc.).

Saving

Save stores the record; Back returns to the list without saving. If another machine with the same name exists, saving is blocked.

Note: If an external system (PLC/ERP) code is needed for integration, it is mapped through a custom field (widget) defined for the machine.
