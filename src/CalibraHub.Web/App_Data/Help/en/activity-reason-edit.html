The Activity Reason Edit screen defines or edits a production downtime/activity reason.

Fields

  • Reason name (e.g. Breakdown, Setup, Break, Waiting for Material).
  • Reason type/class (e.g. planned / unplanned downtime) and status.

Saving

Save stores the record; Back returns to the list without saving.

Note: The defined reasons make up the list the operator selects from when stopping a job on the Production Terminal, and they are used in downtime reports.
