The Import Wizard creates/edits an import template and, using that template, uploads your file and converts it into records. The screen behaves differently depending on the mode it was opened in.

Modes

  • New Template: You define a template from scratch.
  • Edit: You change the mapping of an existing template.
  • Import (Run): You upload a file with the selected template and perform the import.

Template Definition (Mapping)

  • Target record: You select the record type to import (e.g. Account, Material).
  • Column mapping: You map your file's column headers to the fields of the target record (e.g. "Title" → Account Title).
  • Matching key: You specify which field is treated as the unique key for updating an existing record (if no match is found, a new record is created).

Running

  • Upload file → the wizard reads the column headers.
  • Preview: You see the rows and potential errors before importing.
  • Process: Once you confirm, records are created/updated; the result (successful/failed) is reported.

Note: For large files, it is recommended to preview with a small sample first and verify the mapping.
