The Data Import screen lists the templates you have prepared for bulk importing from Excel/CSV files into CalibraHub records (accounts, materials, documents, etc.).

What Is a Template?

An import template defines which record (target) is fed from which file columns. Once defined, a template can be reused to import files with the same structure again and again.

Cards and Actions

  • Each card represents a template (target record type, status).
  • New Template: Opens the wizard to create a new template.
  • Card actions: Import (upload a file and run), Edit (change the mapping), Activate/Deactivate, Delete.

Note: This screen is different from live integration with third-party systems (ERP/Netsis); here, one-off/repeated bulk loading is performed from manually prepared files.
