The Capacity / Load report shows how busy each machine is over the selected period as a heat map. The goal is to see the bottleneck before the work starts.

What Is This Screen For?

  • Rows are machines, columns are the days or weeks you selected.
  • The darker the colour, the higher the utilisation; cells above 100% are overloaded.
  • Hovering a cell shows that period's capacity and load in hours.

How Are Capacity and Load Calculated?

  • Capacity = the machine's working window − public holidays − planned maintenance.
  • Load = production blocks falling in that period + setup blocks.
  • If a block spans two periods, only the part falling into each period is counted.

Note: the date range is calculated including the end day. Working hours and holidays are managed on the "Machine Work Calendar" screen.
