The Document Management screen is a document archive where you upload corporate files such as procedures, instructions, forms, and certificates and manage them with version (revision) tracking.

What Is This Screen For?

All uploaded documents are listed in a card view. Each document is classified under a category/type and tracked with a version number. It is independent of commercial documents (invoices, delivery notes) — free-form files are stored here.

Top Toolbar and Cards

  • Upload Document: Uploads a new file (title, description, category/type, tag).
  • Search / Filter: Narrow down by category, type, and name.
  • Card actions: Download, Edit (title/description/category/tag), Revise (upload a new version), History (version/revision list), Delete.

Revision (Version)

When you upload a new file with Revise, the previous version is archived and the revision number is incremented. This way the full history of a document can be tracked from the History screen.

Note: The categories and types used to classify documents are defined on the "Document Categories" screen.
