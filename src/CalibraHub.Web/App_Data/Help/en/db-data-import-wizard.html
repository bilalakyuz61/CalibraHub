The import wizard walks you through mapping source data onto CalibraHub fields.

Steps

  • Source: pick the connection and the table/query.
  • Target: choose the record type to import (contact, item, document…).
  • Mapping: bind source columns to target fields and mark the key field.
  • Preview: the first rows and any errors are shown; confirming saves the import.

It cannot be saved without a key field — that is the only thing preventing duplicate records on a re-run.
