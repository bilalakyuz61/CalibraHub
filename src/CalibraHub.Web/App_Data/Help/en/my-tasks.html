The My Tasks screen gathers the project tasks assigned to you in a single list. You track, complete, or cancel your own work here.

What Is This Screen For?

  • Lists the tasks assigned to the signed-in user.
  • The Open / All filter shows only pending tasks or all tasks.
  • Each task shows the project, task name, due date, and status.

Task Actions

  • Mark a task finished with Complete; the related project's progress is updated.
  • If needed, you can Cancel it.

Note: For sequential (dependent) tasks, the next step may not open until the previous step is completed; subsequent tasks unlock as tasks are completed.
