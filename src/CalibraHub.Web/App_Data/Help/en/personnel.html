The Personnel Definitions screen lists and defines production personnel in a card view. These are the people who start and complete operations on the Production Terminal (ShopFloor).

What Is This Screen For?

Each card represents one employee. From the top tab bar you can switch to other production definitions such as Operation, Machine, Routing, and Shift.

Cards and Actions

  • The card shows the employee's name, department, and status.
  • New / Edit: Opens the personnel edit screen.
  • Delete: Deactivates/removes the employee.

Note: You do not enter a code for personnel; uniqueness is enforced by name. A PIN or NFC card can be defined for terminal sign-in.
