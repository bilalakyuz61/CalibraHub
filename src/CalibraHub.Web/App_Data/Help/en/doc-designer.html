The Document Designer screen lists and manages, in a card view, the print/output templates of documents such as invoices, delivery notes, quotes, orders, and barcodes.

What Is This Screen For?

Each card represents a document template. When a document is printed, the template defined for that document type is used. Which template is used for which document is determined on the "Design Rules" screen.

Cards and Actions

  • The card shows the template name, document type, and whether it is the default.
  • New Template: Opens the visual designer.
  • Card actions: Edit, Clone (create a copy), Set as Default, Delete.

Note: This screen designs the document's layout/output; the document itself (invoice/delivery note) is created from the relevant module.
