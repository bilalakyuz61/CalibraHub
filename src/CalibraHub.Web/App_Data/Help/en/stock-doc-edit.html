The Stock Document Edit screen is the shared screen where you create and edit warehouse receipt, warehouse issue, and transfer documents. Header details are at the top, line items below.

Header

  • Location: The target or source warehouse for receipts/issues; for transfers, both the source and the target location.
  • Document date, description, and additional header fields depending on the document type.

Line Items

  • Each line has a material, quantity, and unit; for lot/serial-tracked materials, the lot/serial details.
  • Quick line entry with Enter and pasting from Excel are supported.
  • Additional Fields: Custom fields defined for this form appear in a separate section.

Stock Effect and Saving

  • Receipt adds stock, Issue deducts it, Transfer deducts from the source and adds to the target.
  • Save posts the document; if negative-balance control is enabled, insufficient stock may block the operation.
