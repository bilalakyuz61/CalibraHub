The Approval Flow Designer is a visual canvas where you draw an approval process with drag-and-drop nodes. The node palette is on the left, the flow canvas in the middle, the property panel of the selected node on the right, and the General Info / Variables / Revision History tools at the top.

General Info

  • Flow Name and Document / Record Type (which document it applies to).
  • Active switch — inactive flows are not triggered.

Nodes (Palette)

You drag nodes from the palette onto the canvas and connect them with arrows (edges):

  • Start / End: The entry and exit points of the flow.
  • Step: An approval step that requires an approver decision (the actual approval point).
  • Decision: Evaluates a condition and branches yes/no.
  • Parallel: Splits into / joins multiple branches at the same time.
  • Notification: Mail / WhatsApp notification (can send quick approval links).
  • Voting: Votes from multiple people (majority / unanimous).
  • Wait: Waits for a set duration (minutes/hours/days/business days).
  • Set Variable / Integration / Sub-Process / Webhook: advanced steps.

Step Approvers

When a Step is selected, the approver type is set from the right panel:

  • Any user, Specific user, Department (one or more department members) or Requester's manager (resolved at runtime from the organization chart).
  • Each step has Approve, Reject and Timeout (SLA) output connectors; by wiring these to different nodes you define the reject/delay behavior.
  • If an SLA/delay is defined, a reminder notification is sent when the time expires.

Trigger Conditions

Rules determine whether the flow kicks in: Always, Minimum/Maximum amount, Amount range, Sender Tax ID or Department.

Tools

  • Variables: Defines values carried throughout the process.
  • Mini Map: Navigation in large flows.
  • Revision History: Each save keeps a revision snapshot; running (pending) documents continue with the revision they started with — so changing the flow does not break in-progress approvals.
  • Save: Saves the flow (creates a new revision).

Note: If you add {approveLink} / {rejectLink} to the template in a Notification node, recipients can approve or reject with a single click via mail/WhatsApp.
