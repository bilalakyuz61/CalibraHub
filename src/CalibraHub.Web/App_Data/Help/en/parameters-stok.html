The Stock tab defines how warehouse movements affect balances and the rules for the delivery–order link.

Negative Balance Control

When enabled, issues, transfers and production consumption that would drive stock below zero are blocked. When disabled, the system silently allows negative balances.

  • To grant exceptions for specific warehouses, use the per-warehouse negative balance permission field on the Location Definitions screen.

Delivery / Order Binding

  • FIFO Order Binding (Purchase / Sales): When enabled, a delivery line is bound automatically to the oldest open order line for the same account and material; when disabled, the link is made manually.
  • Delivery Without Order Forbidden (Purchase / Sales): When enabled, a delivery that is not bound to an order cannot be saved — every delivery must originate from an order.
  • Order Serial Can Be Changed on Sales Delivery: Allows serial numbers reserved on the order to be swapped at shipment. When disabled, only the reserved serials may be shipped.

Note: Settings apply to newly saved documents; existing movements and balances are not changed retroactively.
