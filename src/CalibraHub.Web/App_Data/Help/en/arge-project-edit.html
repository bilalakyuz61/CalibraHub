The Project Edit screen lets you manage an R&D / product development project in full detail — general info, prototypes, tasks and cost tracking.

General Info

  • Project name, stage/status, owner, dates and description.

Prototypes

The BOM (Bill of Materials) and routing definitions of the project's prototype products. A work order can be opened for prototype production; consumed material and labor are reflected as cost on the project.

Tasks

The project's work breakdown structure (WBS): sequential or independent tasks, owners and due dates. With Apply from Template, a ready-made task set (e.g. sampling process, APQP) can be added to the project; as tasks are completed, the project's progress percentage is updated.

Cost

Costs coming from warehouse issues linked to the project, prototype consumption and work orders are shown aggregated (rollup); the project's total R&D cost is tracked.

Saving

Save stores the project; Back returns to the board without saving.
