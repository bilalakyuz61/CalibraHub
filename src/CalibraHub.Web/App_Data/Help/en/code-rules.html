The Code Rules screen defines how the automatic code (account code / stock code) is generated when a new account or material record is created.

What Is This Screen For?

The code generation rules are listed in a card view. When a new account/material is added, the code is created automatically with the defined format (prefix + incrementing sequence etc.) — reducing the need for manual code entry.

Cards and Actions

  • The card shows the rule name, a format example and the counter.
  • New / Edit: Edits the code format; remove it with Delete.

Note: This screen is reached from the Account Code and Stock Code tabs inside "Design Rules".
