On the Approval Tasks tab you decide, per document type, whether an approval flow starts automatically.

How It Works

  • Enabled type: When a new document is saved, the matching approval flow starts by itself.
  • Disabled type: No automatic start. Users can still trigger the flow manually with Send for Approval on the document — that option is always available.

Where Are Flow Templates Defined?

This tab only answers "should it trigger automatically". Who approves, in which order and under which conditions is configured on the Approval Flow Definitions screen. The link at the bottom of the tab takes you there.

Common Situations

  • Type is enabled but nothing enters approval: there may be no active flow definition matching that document type. Check the flow definitions.
  • When approval is required for a document type, setting the status to "Approved" by hand is locked — the decision comes from the flow.

Note: The change is applied with Save and affects only new records; approval processes already running continue unchanged.
