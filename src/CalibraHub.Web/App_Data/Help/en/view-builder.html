The SQL View Management screen is a system/developer tool that lets you extend the application's database views or build custom read-only views from scratch.

What Is This Screen For?

  • Extending an existing view: Adding joins and computed fields to one of the application's built-in views.
  • New custom view: Building a new view with the visual builder (table/join/field) or with advanced SQL.
  • Safe editing with Cartesian (product) warnings, breakage protection, and revisions/rollback.

Note: Open only to the System Admin; views are read-only projections (they do not change table/data schema). The code-defined baseline is set up at application startup, and your version is safely applied on top of it.
