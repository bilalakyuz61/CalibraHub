The Shift Edit screen defines/edits a production shift.

Fields

  • Shift name (e.g. Morning, Evening, Night).
  • Start / end time and break durations, if any.
  • Shifts that span midnight, such as a night shift, can also be defined.

Saving

Save stores the record; Back returns to the list without saving.

Note: To assign the shift to personnel, use the "Shift Assignments" screen.
