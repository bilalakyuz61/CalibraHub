The Document Design Rule Edit screen defines which document template is used in a specific situation.

Fields

  • Document type: The document the rule applies to (e.g. Sales Invoice, Delivery Note).
  • Design: The template to use (defined in the Document Designer).
  • Criteria: The conditions under which the rule applies — such as account, user, branch, warehouse (multiple values can be selected). If left empty, the rule is general.

Saving

Save stores the rule; Back returns to the list without saving.
