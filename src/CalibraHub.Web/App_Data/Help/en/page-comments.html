The Page Comments screen is the management screen where you monitor, in one place, the feedback/request comments left on screens (they may include screenshots).

What Is This Screen For?

  • Comments are grouped by screen; each comment shows the text, the author, and the date.
  • Comments are treated as a development/improvement queue; processed comments can be closed/deleted.

Note: Comments are left via the pencil (✏️) button on the relevant screen; this screen is for centralized monitoring.
