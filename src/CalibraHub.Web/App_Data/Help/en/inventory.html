The Stock Count screen lists physical stock count documents. You count the actual quantities in the warehouse, compare them with the system balance and correct the differences.

What Is This Screen For?

Each card is one count document. During a count, the counted quantity is entered for each material; the difference against the system balance is calculated automatically, and upon approval the stock is corrected by this difference.

Toolbar and Cards

  • New Stock Count: Opens the edit screen where you select a location and enter the count.
  • The card shows the document number, location, status and date.
  • Card actions: Edit, Delete, audit log.

Note: After approval, count differences are posted to stock as a warehouse receipt (surplus) or issue (shortage) movement.
