The Work Order tab is reserved for company parameters of the production work order module.

Current State

No savable parameter is defined on this tab yet, so the Save button appears disabled while the tab is open. This is expected, not an error.

Other Settings That Affect Work Orders

  • Production tab: ShopFloor PIN limit, permission to edit the recipe of a started work order, repeated components in a recipe.
  • Stock tab: negative balance control, which blocks production consumption from driving stock below zero.
  • Traceability tab: serial number uniqueness scope.

Note: When a work-order-specific parameter is added, it will appear on this tab and the Save button will become active.
