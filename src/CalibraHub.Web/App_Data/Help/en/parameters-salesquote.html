The Sales Quote tab defines which exchange rate is used on foreign-currency documents.

Currency Rate Type

When a currency is selected on a document, this setting decides which rate is pulled from the central bank table for the document's rate date. It applies to all foreign-currency documents, not only quotes.

  • Selling / Buying: Forex rate — for bank transfer based transactions.
  • Effective Selling / Effective Buying: Banknote (cash) rate — for cash transactions.

Which One to Choose

  • If you collect and pay through banks, choose Selling or Buying.
  • Use the selling direction if you price by selling currency to the customer, the buying direction if you purchase currency.

Sales Quote Approval

When enabled, saving a new sales quote starts the matching approval flow automatically; when disabled, no automatic start happens (users can still choose Send for Approval on the document).

  • Enabling the parameter is not enough on its own — an active flow matching this document type must exist on the Approval Flow Definitions screen.
  • When approval is required for a type, setting the status to "Approved" by hand is locked.

Note: The rate is resolved from the document's rate date. Saved documents are not retroactively re-rated; the setting affects subsequent documents. Other approval parameters live on the Purchasing, Sales Order and Demand Records tabs.
