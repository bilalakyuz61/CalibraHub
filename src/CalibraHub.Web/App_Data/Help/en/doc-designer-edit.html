The Document Template Designer is a full-screen editor where you design a document's printed layout with drag and drop. You build the template using bands, fields, and data sources.

Structure

  • Bands: Sections such as document header, line items (repeating), totals, and footer.
  • Fields / Data Source: You drag and place document fields (account, date, amount, line details) and add text/lines/logos/barcodes.
  • Font, alignment, size, and position settings are configured from the panel.

Saving and Preview

  • Preview shows how the template will print with sample data.
  • Save stores the template and makes it available for document printing.
