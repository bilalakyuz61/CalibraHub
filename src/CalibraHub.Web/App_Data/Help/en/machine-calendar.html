The Machine Work Calendar screen defines the machines' weekly working hours and holidays. This calendar determines the capacity windows in machine scheduling.

What Is This Screen For?

  • Working windows: Days of the week and time ranges per machine (e.g. Mon-Fri 08:00–18:00).
  • Holidays: Company-wide holidays; machines are considered non-working on those days.

Note: The Machine Scheduling (Gantt) screen places jobs into the workable windows of this calendar; hours outside the calendar appear shaded.
