The Demand Records tab controls how the "Fulfill from Warehouse" action in the Fulfillment Center behaves.

Preserve Minimum Stock During Fulfillment

When enabled, the distribution and the stock balance view respect the minimum stock level: quantities that would drop stock below the minimum are excluded from fulfillment. A warehouse specific minimum takes precedence; otherwise the material's general minimum applies.

Consolidate Stock on the Counter Document

When enabled, the Goods Issue and Warehouse Transfer documents created by "Fulfill from Warehouse" merge the same material into a single line. When disabled, each fulfillment produces its own line, so you can trace which demand consumed which quantity.

Fulfillment Warehouse Selection

  • Specific Warehouses: Only the balances of the warehouses selected below are used. If none are selected, fulfillment cannot run.
  • Warehouse on the Item Card: Each material's default location is used — suitable when warehouse structure differs from material to material.

Demand Record Approval

When enabled, creating a new demand record (purchase request) starts the matching approval flow automatically; the request cannot be converted into purchasing until it is approved. An active definition must exist on the Approval Flow Definitions screen for the flow to run.

Note: The fulfillment settings only affect the proposal and the shape of the created document; they never change stock balances by themselves. Purchase quote/order approvals are on the Purchasing tab.
