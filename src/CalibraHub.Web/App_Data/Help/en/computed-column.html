Computed Columns let you add a derived field to a table without changing the data. The value is calculated when the data is read, not when it is saved.

What Is This Screen For?

  • You define a new field from existing columns using a formula (e.g. amount × rate).
  • The defined field can be used like a normal column in reports and list screens.
  • The expression is validated before saving; an invalid expression is not applied.

Things To Watch

  • A formula can only reference columns on the same row.
  • The field is read-only; it is displayed, never entered.
  • Heavy formulas can slow down queries on large lists.

This screen is for system administrators; access is restricted because it affects the schema.
