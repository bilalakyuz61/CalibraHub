The Data Visibility Rules screen manages the rules that determine which records each user/role can see (row-based) and which fields are hidden (field-based).

What Is This Screen For?

  • Row masking: For example, a user only sees records belonging to their own department/branch.
  • Field masking: Hides specific fields (e.g. cost, discount) from certain roles.
  • Each card represents a rule; a rule consists of a screen + condition + scope.

Actions

  • New / Edit: Opens the rule editing screen.
  • Delete: Removes the rule.

Note: Masking is an additional layer on top of permissions — even if a user is authorized, they cannot see a masked record/field.
