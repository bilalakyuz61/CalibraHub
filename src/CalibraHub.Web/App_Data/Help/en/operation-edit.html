The Operation Edit screen defines a production operation and its standard times per machine/product.

Fields

  • Operation name (required; uniqueness is enforced by name — no code is entered).
  • Machine / Product Times: Enter how long this operation takes on which machine and for which product (setup + unit time). These times are used in capacity and work order planning.

Saving

Save stores the record; Back returns to the list without saving.

Note: Times are managed per operation on a single screen; the routing sequences operations from a separate screen.
