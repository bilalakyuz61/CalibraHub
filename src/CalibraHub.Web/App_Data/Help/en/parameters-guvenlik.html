The Security tab defines the session timeout and the audit log retention policy.

Session Idle Timeout (minutes)

If the user performs no mouse/keyboard action for this period, the session ends. Before closing, a countdown warning is displayed; if the user continues, the timer restarts.

  • 0 = off (no idle timeout).
  • Recommended: 30 minutes. Use a shorter value on shared terminals.

Audit Log Retention (days)

Insert/update/delete operations and session events are stored as daily JSON files in the application directory. Daily files older than this period are deleted automatically.

  • 0 = keep forever (no log file is deleted).
  • Default is 365 days. Align it with your legal retention period if you are subject to audit.

Note: You can review stored logs on Settings → Audit Logs. Shortening the period causes old files to be permanently deleted at the next cleanup.
