Endpointler ekranı; entegrasyonun kullandığı dış sistem uç noktalarını (API adresleri/servisleri) listeler.

Ekran Ne İşe Yarar?

  • Hedef sistemin desteklediği servis/uç noktaları gösterir (ör. cari yaz, stok oku).
  • Entegrasyon tanımında hangi endpoint'in kullanılacağı buradan seçilir.

Not: Endpoint kataloğu, bağlı sağlayıcının tanımından beslenir.
