Kod Kuralı Düzenleme ekranı; cari veya stok için otomatik kod formatını tanımlar.

Alanlar

  • Format: Önek/sabit metin, tarih bileşeni ve artan sıra numarası.
  • Sıra uzunluğu ve başlangıç/mevcut sayaç.
  • Varsa kapsam (hangi grup/tipte geçerli).

Kaydetme

Kaydet ile kural saklanır; Geri kaydetmeden listeye döner.
