Belge Tasarım Kuralı Düzenleme ekranı; belirli bir durumda hangi belge şablonunun kullanılacağını tanımlar.

Alanlar

  • Belge tipi: Kuralın geçerli olacağı belge (ör. Satış Faturası, İrsaliye).
  • Tasarım: Kullanılacak şablon (Belge Tasarımcısı'nda tanımlı).
  • Kriterler: Kuralın uygulanacağı koşullar — cari, kullanıcı, şube, depo gibi (birden çok değer seçilebilir). Boş bırakılırsa kural geneldir.

Kaydetme

Kaydet ile kural saklanır; Geri kaydetmeden listeye döner.
