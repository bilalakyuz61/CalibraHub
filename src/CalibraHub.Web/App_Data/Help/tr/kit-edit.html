Kit (Paket Ürün) Düzenleme ekranı; birden çok malzemenin birlikte satıldığı paket ürünün içeriğini ve fiyatlama şeklini tanımlar.

Kit Nedir?

Kit; stokta kendisi tutulmayan, satış anında bileşenlerine "patlatılan" bir paket üründür (ör. Masa + 4 Sandalye seti). Sipariş kitin kendisiyle alınır, sevkiyat bileşenleriyle yapılır.

Alanlar

  • Kit bilgileri ve versiyon.
  • Bileşen satırları: Pakete giren malzemeler ve adetleri.
  • Fiyat modu: Sabit paket fiyatı veya bileşen toplamı (roll-up).

Kaydetme

Kaydet ile saklanır; Geri kaydetmeden listeye döner.

Not: Kit satış belgelerinde tam set olarak izlenir; kısmi teslimatta set bütünlüğü korunur.
