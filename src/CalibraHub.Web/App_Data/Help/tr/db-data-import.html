Veritabanı Aktarımı; başka bir SQL veritabanındaki kayıtları CalibraHub'a eşleme tanımıyla aktarmanızı sağlar. Aktarım tekrar çalıştırılabilir: aynı kayıt ikinci kez eklenmez.

Akış

  • Bağlantılar ekranında kaynak veritabanını tanımlarsınız.
  • Sihirbaz ile kaynak tablo/sorgu seçilir, kolonlar CalibraHub alanlarıyla eşlenir.
  • Bu ekranda tanımlı aktarımları görür, çalıştırır ve sonuçlarını izlersiniz.

Dikkat Edilecekler

  • Anahtar alan zorunludur — kaydın daha önce aktarılıp aktarılmadığı buradan anlaşılır.
  • Stok aktarımı bakiye aynasıdır, hareket üretmez; hareket istiyorsanız sayım fişi oluşturup yansıtın.
  • Çalıştırmadan önce önizlemeyi inceleyin; hatalı satırlar orada listelenir.
